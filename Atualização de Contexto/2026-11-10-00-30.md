## 1. O que é o projeto

AppDeck é um "Stream Deck portátil": um painel web que monitora e controla um PC (CPU/RAM/FPS + botões de atalho) de um dispositivo móvel. Fase 1 = rede local, usuário único, sem login/anúncios, Windows 10/11 64-bits. Fontes de verdade: `SPEC.md`, `docs/intent/`, e este mesmo arquivo.

## 2. Arquitetura

Monorepo com npm workspaces:
- **`shared`** — tipos/protocolo comum entre agente e web.
- **`agent`** — roda no PC, coleta métricas e envia comandos. Fala com a web via **WebSocket** (dep `ws`). Config persistida em `agent/config.json`.
- **`web`** — React 18 + Vite 5 + Tailwind + TypeScript + Vitest. É o painel que o usuário vê no celular.

## 3. Como rodar

```bash
npm install          # instala todos os workspaces
npm run build -w web # build do painel (gera web/dist)
npm test             # roda vitest
```

Servidores de preview (via `.claude/launch.json`):
- `web` → **porta 5173** (`web/dist`, **o build** — rode build antes de servir).
- `mockup` → **porta 5175** (`web/public/mockup.html`, HTML estático de referência).

Pegadinhas:
- O **mockup** (`web/public/mockup.html`) e o **React** (`web/src`) andam lado a lado; o usuário quer que o **React espelhe o mockup** sempre (mesmos componentes, dropdowns, estilos).
- Tema (dark/light) só funciona se as cores usarem **variáveis CSS** (`var(--panel)`, `var(--border-2)`, etc.). Cor hardcoded em hex/rgba **quebra** o light mode — foi a raiz de um bug recente.
