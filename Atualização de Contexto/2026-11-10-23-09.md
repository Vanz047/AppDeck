## 1. O que é o projeto

AppDeck é um "Stream Deck portátil": painel web que monitora e controla um PC (CPU/RAM/FPS + botões de atalho) de um dispositivo móvel. Fase 1 = rede local, usuário único, sem login/anúncios, Windows 10/11 64-bits. Fontes de verdade: `SPEC.md`, `docs/intent/`, e este arquivo.

## 2. Arquitetura

Monorepo com npm workspaces:
- **`shared`** — tipos/protocolo comum (`shared/src/protocol.ts` é a fonte única de verdade: `validateMessage`, `Action`, `Metrics`, `Config`, etc.).
- **`agent`** — roda no PC, coleta métricas e executa comandos. WebSocket na porta 5555 (dep `ws`). Config em `agent/config.json`.
- **`web`** — React 18 + Vite 5 + Tailwind + TypeScript + Vitest. É o painel no celular.

## 3. Como rodar

```bash
npm install          # instala todos os workspaces
npm test             # roda vitest (66 testes)
npm run build -w web # build do painel (gera web/dist)
```
