## 1. O que é o projeto

AppDeck — "Stream Deck portátil" web-first: interface React no celular/tablet conecta via WebSocket a um agente Node no PC Windows (porta 5555). O celular exibe CPU/RAM/FPS em tempo real (~1s) e dispara ações (abrir Discord/OBS, screenshot) sem sair do jogo. Fase 1 = rede local, sem login, sem multi-usuário. Fontes de verdade: `SPEC.md`, `shared/src/protocol.ts`, `tasks/todo.md`.

## 2. Arquitetura

Monorepo npm workspaces (3 pacotes):
- **shared/** — contrato único (`protocol.ts`): `Metrics`, `Action`, `Config`, `validateMessage`
- **agent/** — Node/TS + `ws` server em `:5555`: coleta métricas (`os` + FPS nativo), executa ações (`openApp`, `screenshotFull/Crop`), persiste `config.json`
- **web/** — React 18 + Vite 5 + Tailwind + TS: cliente WS (`useAppDeckWS`), tabs (Perf, Audio, Jogos, Discord, Stream, Config), componentes reativos

Protocolo: WebSocket JSON, sem auth (rede local). Mensagens: `action`, `config.get|set` (web→agent); `metrics` (1s), `config`, `ack`, `error` (agent→web).

## 3. Como rodar

```bash
# Raiz
npm install
npm run dev          # sobe agent + web juntos
npm test             # todos os testes (vitest)
npm run lint         # eslint

# Agente (PC)
npm run dev:agent    # WS server em :5555 (tsx watch)
npm run build:agent  # tsc → dist/
npm test:agent       # testes do agente

# Web (celular)
npm run dev:web      # Vite dev server em :5173 (host: true → acessível na LAN)
npm run build:web    # build produção → web/dist/
npm test:web         # testes da web
```

Preview servers configurados em `.claude/launch.json`:
- `web` → serve `web/dist` em :5173
- `mockup` → serve `web/public` em :5175
